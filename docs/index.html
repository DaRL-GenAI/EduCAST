EduCAST: A Multi-Agent System for Personalized Educational Video Generation with Closed-Loop Review

Qingyue Chen*, Aarshdeeep Singh Nandra*, Huaiyuan Yao*, Varun Shourie, Rayan Kazi, Hua Wei
Arizona State University   *Equal Contribution

Accepted to the AAAI-27 Demonstration Program

Abstract

Personalized instructional videos are costly to produce because lesson planning, visual design, narration, rendering, and quality control must be coordinated for each learner. We present EduCAST, an open-source demonstration system that turns a topic, learner profile, and learning objective into an inspectable educational lesson. A multi-agent pipeline creates a learner-conditioned plan, converts segments into animation code or structured specifications, renders narrated media, and uses VLM review to trigger localized repairs. The interface exposes segment plans, media previews, and review feedback, while a browser player combines video, illustrations, and interactive practice. A pilot comparison examines output quality and the overhead of the reviewer loop.

How does EduCAST work?

EduCAST makes Educational videos that are Controllable, Adaptive, and Self-correcTing. It combines explicit lesson and scene specifications with heterogeneous renderers, a review-and-repair loop, and a browser lesson player.

Learner-conditioned planning, visual specification, rendering, and scene-level review. Feedback identifies the scenes to repair and recheck.

1) Instructional Planner

Builds an ordered lesson blueprint from the topic, learner background, and learning goal: scene titles, narration, visual briefs, modality choices, and the teaching elements each scene must show.

2) Visual Designer

Turns each scene into something renderable: Python or JavaScript animation code, image-generation prompts, or code for an interactive exercise, under shared layout constraints.

3) Rendering Engine

Renders every scene independently, synchronizes it with synthesized narration, and packages a lesson bundle that the browser player can pause at planned practice points.

4) VLM Reviewer

Checks sampled frames against the scene brief and narration, flags missing content, wrong formulas, unreadable labels, and occlusion, then patches or regenerates only the flagged scenes.

Does the reviewer loop help?

Five human evaluators scored 32 sections across five lessons on six 1–5 quality scales, comparing EduCAST with and without reviewer-guided repair. The reviewer improves all six dimensions, with the largest gains in visual quality and multimedia design, at an estimated cost below $1 per output minute.
