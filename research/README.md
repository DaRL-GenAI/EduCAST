# Research materials

These files are separate from the current generation pipeline.

- `baseline/`: Colab comparison runners for Code2Video, Manim, Remotion and
  TeachingMonster. They require the external upstream projects and their original
  Google Drive directory layout. `api_usage_tracker.py` records baseline usage.
- `notebooks/eval.ipynb`: historical evaluation definitions; requires an external
  `Teaching_Video_Generation` project providing `teachgen.eval`, not included here.
- `topics.xlsx`, `data/`: topic lists and structured teaching requests.

For current generation, use the [main setup](../SETUP.md).
